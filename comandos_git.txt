git init . _> cria um repo git na pasta atual
git status -> verifica status da branch
git add -> adiciona arquivo para commit
git commit -m "msg"-> faz o commit do que foi adicionado
git log -> mostra o histórico dos commits


## FLUXO DE TRABALHO

1. criar o diretório do projeto
2. iniciar o git dentro do diretório criado (git init .)
3. edita ou cria arquivos
4. git status
5. git add <nome arquivo>
6. git status
7. git commit -m "mensagem"
8. git status
9. volta para o passo 3
